# visioai.github.io

Not a site. This repository exists only to keep the old address alive: it
redirects `visioai.github.io` to **https://visiogallery.app**, carrying the
path over, so old links and search results still land somewhere.

The site itself lives in the `visio-site` repository and is deployed by
Cloudflare Pages. Do not delete this repository — deleting it frees the name
`visioai.github.io`, which anyone could then claim.
